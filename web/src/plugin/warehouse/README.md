# 仓储前端

页面复用框架 `gva-search-box`、`gva-table-box`。送货单编辑页使用十进制预览金额，服务端负责最终精度校验与落账。

`master.vue` 按菜单路由名区分单位、客户、类别、物料，包含列表、搜索、分页和编辑。`delivery.vue` 包含列表和全屏录入；基础资料与送货单列表双击记录或点击编辑操作后，均在系统顶部路由标签中打开独立的详情页。`reconciliation.vue` 使用默认收起的统一方案操作侧栏；筛选、显示列变化需主动查询，汇总覆盖全部匹配数据。

仪表盘仅显示送货单总数、待审核数、已审核数、本月送货单数；使用送货单只读列表接口的分页总数统计，每项均以 `pageSize=1` 请求，不读取或展示业务明细。月份按上海时区的送货时间范围计算。顶栏不显示授权版演示或视频教程入口。统计卡片上方显示最多 6 个当前用户有权限访问的菜单；首次无访问记录时按菜单 ID 升序展示，已有记录时按访问次数、最后访问时间降序排列，数据保存在服务端并按登录用户隔离。

## 基础资料

- 类别页按当前树节点筛选；收起树不清除筛选。类别导入的 `ROOT` 只表示虚拟根。
- 物料单位按完整集合提交，可重新指定基本单位，始终要求唯一启用基本单位且系数固定为 `1`；重复单位和缺少基本单位在提交前拒绝。被历史明细引用的绑定不得删除，允许调整基本标记、系数及停用原基本单位，但不改写历史单据换算快照。
- 物料的客户、类别可以不填；填写时需选择有效资料。
- 物料、客户和部门的助记符支持以逗号、中文逗号、分号或空白分隔多个值，输入任一助记符均可匹配；手改后，名称变化不会覆盖。
- 图片仅允许 jpg/jpeg/png/bmp，超过 1MiB 不上传、不压缩。
- Excel 响应若是 JSON，展示业务错误和行号，不保存成 xlsx。
- 列表页面使用 `py-2` 间距；客户选择后仅显示名称，候选左侧显示名称、右侧以辅助色显示编号。编辑表单宽屏一行四列，中等屏幕两列、窄屏一列，单位集合保持整行。
- 新增客户、类别、物料时调用 `POST /warehouse/master/reserveCode`（需显式授权），分别预填 `KH`、`LB`、`WL` 加六位流水号；单位无编号字段。流水按资料类型独立持久化，不按日期重置，事务锁和唯一资源键处理并发首次分配，跳过手工/导入及已删除历史编号，不使用最大编号加一。取消新增会留下空号，编号仍可手动修改，保存沿用原编号唯一性校验。升级需启动后端以迁移 `wh_master_code_counters`。
- 基础资料保存后留在当前编辑页，并使用返回的 ID、版本及审计信息继续修改；新增首次保存转为该记录的编辑地址，不再次新建。系统标签按路由、单据及账号隔离缓存；切换标签不重置其他编辑页及列表查询。

基础资料表格将创建人、创建时间、修改人、修改时间、审核人和审核时间分列展示；人员名称从用户列表读取昵称。送货单列表和录入区的送货日期只精确到日期，创建时间和审核时间仍显示完整时间。
基础资料、送货单和对账结果表的数据列支持服务端排序；送货单和基础资料排序作用于全部筛选结果，对账先对全部匹配分组排序再分页。基础资料、送货单列表和对账结果表的拖拽列宽按表格类型及登录用户保存到服务端，重进页面后恢复。

## 送货单

- Enter / Tab 前进，Shift+Enter / Shift+Tab 返回上一录入字段；行内和跨行均按当前显示列顺序跳过“明细备注”，需要时用鼠标点击备注录入。手动进入备注后仍可用上述按键离开，定位到相邻的常用录入字段。普通输入、blur 和输入法组字不提交。
- 最后一格完成且末行已有物料时只追加一次空行。完全空白尾行不提交，部分填写行报错。
- 数量、单价及金额允许 `0`，可先保存已选物料的零值明细；仍校验非负数、十进制精度和范围。数量和单价保持字符串，编辑显示去掉小数末尾多余的 `0`。数量为零时不反算单价，服务端保留提交的单价和明确填写的金额，避免除零。
- 数字录入接受 `.5`、`4.`、`.05`、`982.`，移焦后规范为 `0.5`、`4`、`0.05`、`982`；清空字段后按已填值补算或补零。清空金额且已填数量、单价时，Enter / Tab 重算金额，并沿用末格完成后追加空行的规则；未选物料时可从数量向前返回物料，不因必填校验锁住返回路径。
- 送货单单头客户支持按客户名称、助记符和编号搜索；客户下拉与部门历史候选按 Enter 确认当前高亮项，未手动调整候选时沿用组件默认首项。物料选择不按客户过滤，切换单头客户不清空已选明细。
- 列表筛选区的物料条件使用内联多选下拉框，不打开编辑页的添加物料弹窗。字段获焦或点击后自动聚焦内部搜索框，支持按名称、编号、助记符搜索、全选当前可见、取消全选及清空；仅选一项显示物料名称，多项显示数量，悬停显示所选物料名称及编号，关闭下拉保留选择。点击「查询」才应用条件，以 `materialIds` 逗号分隔 ID 查询包含任一所选物料的送货单，仅匹配未软删除的明细；分页保留条件，重置清空物料选择，非法 ID 返回 `VALIDATION_FAILED` 及 `materialIds` 字段。
- 多选弹窗同一次选择去重，但已有单据允许再次追加同一物料为独立行。
- 批量审核和反审核只作用于当前页勾选且状态匹配的单据；逐单提交版本号，部分失败时提示已完成数量，刷新后可继续处理。
- 基础资料提供部门列表与编辑页，部门支持多个助记符；升级时导入历史送货单部门。录单候选匹配部门名称或助记符，仍可自由输入新部门并随单据保存登记。修改部门资料名称不重写历史单据部门快照；对账仍按历史快照筛选。
- 对账表支持按部门维度分组；维度值来自送货单单头快照。
- 送货单列表默认在客户列右侧展示部门；字段顺序可在单据展示设置中调整。部门条件按单头精确筛选。对账表部门条件按历史快照精确筛选，并随分页、导出和打印查询生效。
- 送货单列表金额列居中；创建人、修改人、审核人优先按用户 ID 显示用户昵称，缺少用户记录时回退到单据快照。
- 批量选择物料采用候选/已选双栏表格，两侧独立按编号、名称、规格或助记符搜索，候选侧支持类别及其子类别筛选；两侧均可勾选或单击行切换勾选。中间 `>>` / `>` 将当前可见全部候选 / 勾选候选移入已选，`<` / `<<` 将勾选已选 / 当前可见全部已选移回候选。已选物料从候选中排除，按移入顺序保留且同次选择去重；勾选和移入仅暂存，点击“追加为独立明细行”才添加到送货明细，取消不添加、重新打开清空暂存与筛选。加载期间锁定关闭、取消和双侧操作。物料主数据无原物料/商品类型或启停字段，弹窗不显示这些虚构筛选。
- 编辑页“保存”成功后留在当前单据，使用服务端返回的明细 ID 和新版本继续编辑；新建保存后切换至该单据的详情地址。“保存并继续新增”成功后清空表单并预占新单号，继续录入新单。
- 送货单编辑页的物料编号列支持按编号、名称或助记符搜索；选中后仅显示编号，下拉候选仍显示编号、名称及规格。可批量选择物料，也可在编辑页新建物料并添加到当前单据。打开新建物料弹窗时自动预占物料编号；物料名称输入或预填后按名称自动生成助记符。新建物料的客户和类别非必填，基本单位需先存在。
- 物料编号 Enter 由选择器原生确认当前高亮候选（无手动定位时默认首项），支持鼠标和上下方向键定位；确认后关闭面板并在加载成功后聚焦数量，重复确认当前物料也移至数量。单击详情行可切换勾选，已选行显示选中底色，与双击编辑状态独立。
- 物料选中后数量、单价默认填 `0`，焦点跳过自动带出的单位到数量；单位下拉框不标注“基本”，关闭下拉框后按 Enter 移至下一个录入焦点。数字输入框获焦时全选内容，单价或数量变化即以十进制精度更新金额；送货日期输入支持左右方向键按天调整。下拉候选左侧显示名称、右侧以辅助色显示编号，新增空行、选择物料及新建物料操作在内容滚动时保持可见。
- 明细可编辑单元格悬停显示虚线，单击进入对应字段编辑；只挂载一行编辑控件，编辑前后保持行高一致，点击行外结束编辑。勾选行后可集中移除，确认后仅修改本地表单，保存后才生效。明细金额及合计按逐行四舍五入到两位小数计算；金额字段显示时去除小数末尾无效的零（如 `44.00` 显示为 `44`、`44.40` 显示为 `44.4`），合计仍显示两位小数；手改金额反算四位单价，服务端以明确提交的金额落账并校验范围。
- 明细“序号”列可拖动排序，显示拖动预览和目标插入位置；放下才修改本地顺序，保存后按该顺序持久化，取消拖动不改变顺序。
- 明细提供“明细备注”字段，随保存、复制及草稿保留；列表“明细备注”筛选以 `detailRemark` 查询备注包含指定文字的未删除明细，单据去重并与其他条件共同生效。
- 列表查询条件、分页、排序及更多筛选展开状态保存在当前账号的浏览器会话中；未保存的新单和已有单据草稿按账号及单据分别保存。编辑/列表或其他标签切换不清空内容；显式重置、重新读取、新建及成功保存按各自操作更新或清理状态，不跨账号共享，已有草稿保留原版本参与冲突校验。
- 列表和编辑页按钮不再显示“批量”字样，多选审核、复审、移除等功能保持不变；明细操作列按钮右对齐。
- 送货单详情页固定显示标题与审核状态，单据信息和明细在中间区域滚动；底部提供刷新、新增、上一张/下一张及当前状态允许的保存、审核/反审核、删除操作。已审核单据额外提供「复制单据」，复制客户、部门、日期和物料明细至新草稿，重新预占单号，不复制原单身份、审核状态、审核信息或明细 ID，且不修改原单；上一张/下一张按当前加载列表顺序切换，有未保存修改时切换或新增会确认。
- 状态为未审核、已审核、已复审；已审核单据可填写选填意见后复审，已复审必须取消复审后才能反审核。列表支持批量复审及批量删除，删除仅作用于未审核单据，逐单校验版本并记录删除审计。
- 新建和编辑点击审核通过 `review: true` 在同一事务中保存并审核，需要保存和审核两类权限；不采用先保存后调用审核的非原子方式。
- 列表修改人昵称 `updatedByName` 和修改时间 `updatedAt` 可在单据展示设置中调整。
- 送货单 Excel 尚未实现，页面不显示不可用的导入/导出按钮。

### 单据展示设置

- 入口为「仓库管理 → 单据展示设置」独立菜单，仅配置送货单，不是列表上的列勾选弹窗。
- 「列表展示」可选择送货日期默认范围：系统默认（不预设日期）、本月、近 7 天、近 30 天、今天、昨天、本年。日期按上海时区计算，滚动范围包含当天；列表重置时恢复该默认值。
- 筛选字段可在「默认筛选」「更多筛选」「未使用字段」之间拖拽并调整顺序；送货日期不可移除。更多筛选在送货单列表中默认收起；移入未使用区的字段清空值且不参与查询。物料条件默认显示在客户条件之后；已有筛选布局保持原样，可从未使用字段中移入。
- 列表列可在展示区内拖拽排序，在展示区和可用字段区之间拖拽调整显隐，并设置列宽。超出页面宽度时在展示区内横向滚动；“显示操作列”可控制列表业务操作列显隐，默认显示。序号、勾选列仍由系统控制。
- 「详情展示」配置明细列顺序、显隐、宽度及冻结至第几列。物料编号、名称、单位、数量、单价、明细备注为必显列，不可移除；明细备注内容可留空，旧列配置自动补入该列。规格、金额可选。键盘按显示的可编辑列顺序移动，但始终跳过明细备注，不受备注列位置影响；校验与账务计算不因布局设置改变。
- 编辑已有送货单时先使用明细快照渲染页面；单位候选在首次展开对应单位下拉框时按需加载，同物料在当前页面共用请求，避免打开单据时逐行请求物料详情。
- 配置复用 `PUT /user/setSelfSetting`，存放在当前登录账号 `originSetting["warehouseDocumentDisplay.delivery"]`。只修改自己的配置并保留其他偏好，不提供跨员工复制。重新登录、刷新页面或返回已缓存列表时应用已保存配置。


## 对账

- 默认收起“报表方案操作面板”，图标展开后在同一面板勾选显示列并维护个人/共享方案，不再分开两个页签。搜索区提供选择方案；方案只保存列及顺序，不保存筛选条件，维护动作仍遵守个人所有者及共享权限。
- 搜索区常规宽度为一行五列，窄屏自适应。送货/审核日期均支持今天、昨天、今年、去年、上周、本周、本月、上月和前月；日期按上海日历计算，周一为一周开始，结束日期包含当天。
- 单据状态支持草稿、已审核、已复审多选，默认已审核和已复审；清空状态亦按这两个默认状态查询。部门下拉来自未删除历史单据快照，支持搜索；查询、分页、导出、打印沿用相同条件。
- 所选维度决定分组。结果表采用 14px 字体、紧凑条纹行、固定序号列，数量、单价、金额等指标居中；底部汇总行与列对齐，金额、数量和基本数量均汇总全部匹配结果，不受分页影响。
- 按住表头文字并横向移动，可看到跟随鼠标的浮动表头、插入线和其他列实时让位，不是交换落点列；靠近结果表左右边缘会自动横向滚动。松开鼠标才提交新顺序，当前结果、导出、打印、后续查询及方案保存同步使用新顺序；拖动期间导出、打印及方案仍使用原顺序。Esc、取消指针、窗口失焦或在表头区域外松开会取消预览。也可聚焦表头后按 Alt+左右方向键调整；序号不可移动，普通单击排序及边缘拖拽列宽保持独立，勾选增减显示列仍需查询。
- 结果全屏只铺满当前路由标签的内容面板，不覆盖系统导航及标签栏；保留汇总、分页、导出及打印，点击退出图标或 Esc 返回。
- 单价不可跨组累加；数量与基本数量按服务端精度直接累计。
- 结果值按名称/编号字段显示，不附加内部标识号：客户仅显示客户名称，物料编号和名称、单位均不显示 ID。
- 未显示的指标不显示对应汇总值。
- 导出和打印使用全部匹配分组，不是当前页。
- 打印内容按文本转义。浏览器焦点和纸张分页未验证。

## 部署与权限

- Go 后端需重新编译启动；启动时注册并修复单据展示设置菜单，已有送货单菜单权限的角色会追加获得此配置菜单，不覆盖其他菜单授权。重登或刷新后加载新菜单。
- 列宽及展示配置复用系统用户 `originSetting`，通过 `setSelfSetting` 合并保存，不新增业务数据表。送货单数据列宽统一存入展示配置；基础资料、对账表及系统辅助列继续使用原列宽键。
- 仓库业务表统一继承 `BusinessModel`，含主键、创建/更新时间、`deleted_at`、`deleted_by`、`is_deleted`、创建/修改/审核人及版本号。软删除同步记录删除人和标记，查询以 `deleted_at` 为权威。对账默认包含未删除且已审核或已复审明细；显式状态条件同时作用于查询、导出和打印。
- 沿用 JWT/Casbin，业务 API 权限仍须显式授权。配置保存要求 `PUT /user/setSelfSetting` 权限；录单角色需要资料列表/物料详情的只读权限；对账的列字典、历史候选、query、export、printData 和方案 CRUD 分别授权。
- 共享方案额外需要 `POST /warehouse/schemes/publish` 权限，个人方案仍按所有者隔离。只保存列顺序，不保存筛选；临时改列不自动覆盖方案。
