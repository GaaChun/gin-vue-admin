# 仓储前端

页面复用框架 `gva-search-box`、`gva-table-box`，不在组件内重算账务金额。

`master.vue` 按菜单路由名区分单位、客户、类别、物料，包含列表、搜索、分页和编辑。`delivery.vue` 包含列表和全屏录入；基础资料与送货单列表双击记录或点击编辑操作后，均在系统顶部路由标签中打开独立的详情页，编辑内容以页面形式展示。`reconciliation.vue` 使用可收起的侧栏分离方案管理与列设置，查询区按宽度自适应，结果表固定序号列并提供横向滚动、分页和全局汇总。方案和筛选条件相互独立，修改条件或列后需主动查询。所有页面自行加载数据，不需要传入 loader。

仪表盘仅显示送货单总数、待审核数、已审核数、本月送货单数；使用送货单只读列表接口的分页总数统计，每项均以 `pageSize=1` 请求，不读取或展示业务明细。月份按上海时区的送货时间范围计算。顶栏不显示授权版演示或视频教程入口。

## 基础资料

- 类别页按当前树节点筛选；收起树不清除筛选。类别导入的 `ROOT` 只表示虚拟根。
- 物料单位按完整集合提交。基本单位系数固定为 `1`，重复单位和缺少启用基本单位在提交前拒绝。
- 物料的客户、类别可以不填；填写时需选择有效资料。
- 助记符手改后，名称变化不会覆盖。
- 图片仅允许 jpg/jpeg/png/bmp，超过 1MiB 不上传、不压缩。
- Excel 响应若是 JSON，展示业务错误和行号，不保存成 xlsx。

基础资料表格将创建人、创建时间、修改人、修改时间、审核人和审核时间分列展示；人员名称从用户列表读取昵称。送货单列表和录入区的送货日期只精确到日期，创建时间和审核时间仍显示完整时间。

## 送货单

- Enter/Tab 或选择确认后才移动焦点；普通输入、blur 和输入法组字不提交。
- 最后一格完成且末行已有物料时只追加一次空行。完全空白尾行不提交，部分填写行报错。
- 数量 `0` 拒绝，单价 `0` 允许。数量和单价保持字符串。
- 送货单单头客户仍为必填，支持按客户名称、助记符和编号搜索；物料选择不按客户过滤，切换单头客户不清空已选明细。
- 多选弹窗同一次选择去重，但已有单据允许再次追加同一物料为独立行。
- 批量审核和反审核只作用于当前页勾选且状态匹配的单据；逐单提交版本号，部分失败时提示已完成数量，刷新后可继续处理。
- 送货单部门为自由文本，输入时按不区分大小写的子串匹配历史单据部门；可直接输入新部门。
- 对账表支持按部门维度分组；维度值来自送货单单头快照。
- 送货单列表部门条件按单头部门精确筛选；对账表部门条件按历史快照精确筛选，并随分页、导出和打印查询生效。
- 编辑页“保存并继续新增”先保存当前单据；成功后切换到新建状态、清空录入内容并预占新单号，保存失败时保留当前表单。
- 送货单 Excel 尚未实现，页面不显示不可用的导入/导出按钮。

## 对账

- 所选维度决定分组。结果表采用紧凑条纹行、固定序号列和指标右对齐；底部汇总行与列对齐，金额、数量和基本数量均汇总全部匹配结果，不受分页影响。
- 单价不可跨组累加；数量与基本数量按服务端精度直接累计。
- 结果值按名称/编号字段显示，不附加内部标识号：客户仅显示客户名称，物料编号和名称、单位均不显示 ID。
- 未显示的指标不显示对应汇总值。
- 导出和打印使用全部匹配分组，不是当前页。
- 打印内容按文本转义。浏览器焦点和纸张分页未验证。

## 部署与权限

- 前端刷新即可加载页面修改；Go 后端需重新编译启动，才能使用新增报表和方案路由及 API 元数据。
- 沿用 JWT/Casbin，不自动授予业务角色权限。录单角色需要资料列表/物料详情的只读权限；对账的列字典、历史候选、query、export、printData 和方案 CRUD 分别授权。
- 共享方案额外需要 `POST /warehouse/schemes/publish` 权限，个人方案仍按所有者隔离。只保存列顺序，不保存筛选；临时改列不自动覆盖方案。
